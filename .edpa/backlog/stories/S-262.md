`_id_ledger.py`: reserve a number by pushing one commit to a ref of the
shared remote, accepted by the server only while the ref still points
where the client saw it. Pure git plumbing — no working tree, no index,
no hooks.

Done when: concurrent callers in several clones and worktrees never get
the same number; a lost race retries; a refusal, a lost acknowledgement,
a rewound / deleted / diverged remote are each handled; the module never
creates a ledger on its own.

Verified by `tests/test_id_ledger.py` (hermetic, bare repo as origin),
plus one manual run against a throwaway GitHub repository.
