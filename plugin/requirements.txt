# EDPA plugin runtime Python dependencies.
#
# When installed via Claude Code's marketplace, the SessionStart hook
# (edpa/scripts/hooks/install_deps.sh) installs these on first launch and
# skips on subsequent sessions via a marker file in ${CLAUDE_PLUGIN_DATA}.
#
# When installed via curl|sh (install.sh), run manually after install:
#   pip3 install -r .claude/requirements.txt
# or invoke `/edpa:setup` (Claude Code) which delegates to project_setup.py.
#
# Set EDPA_NO_AUTO_DEPS=1 to skip the SessionStart auto-install entirely
# (mirrors the auto_update_engine opt-out for the engine vendor hook).
#
# Upper bounds are deliberate: the hook installs into the user's shared
# environment, so a breaking new major must not be auto-pulled onto every
# fresh install. (ruamel.yaml breaks API across 0.x minors — cap at the
# first minor above the range the suite runs on.) Bump caps consciously,
# with a test run.
